# ATM10 @@MCVER@@ 繁體中文（台灣）漢化包 · 客戶端

| 項目 | 版本 |
|---|---|
| 整合包 | All the Mods 10 **v@@MCVER@@** |
| Minecraft | 1.21.1 |
| 載入器 | NeoForge @@NEOFORGE@@ |

**必須與整合包版本對應，不能跨版本用。只要裝這一包就夠了**，不需要先裝簡體中文包或任何其他漢化。

## 安裝

1. 把整個 `atm10-zh_tw-client` 資料夾放進 ATM10 的**實例資料夾**（含 `mods` 與 `options.txt` 的那一層）。
   放錯地方也沒關係，安裝器會請你手動輸入路徑。
2. 執行安裝器：Windows 雙擊 `雙擊安裝-Windows.bat`（亂碼時改用 `install-windows.bat`）；
   macOS / Linux 在終端機執行 `bash install.sh`。
3. 選 **[1] 應用漢化**：先備份、再複製檔案並自動啟用資源包。
   中途詢問的「JEI 拼音搜尋」（用漢語拼音首字母搜物品）是選用的，不需要可以略過。
4. 進遊戲 → 選項 → 語言 → 選 **Chinese (Traditional) (Taiwan)**。
5. 選項 → 資源包：「ATM10漢化包-@@MCVER@@」要在**已選取那一側的最上方**。

原本裝過簡體版的話，裝完到 選項 → 資源包，把簡體版的漢化資源包（名稱是簡體字的那一個）移出已選取即可。

## 升級 / 還原

再執行一次安裝器：有新版時選單會多出 **[u] 一鍵下載並更新**；要回到安裝前選 **[3] 恢復備份**。

## 常見問題

- **裝完還是英文**：確認資源包已啟用且在已選取的最上方、語言是 Chinese (Traditional) (Taiwan)。
- **只有原版的方塊／物品是英文**：啟動器沒把原版語言檔下載完整，對這個實例做一次修復即可。
- **改了沒生效**：資源包按 F3+T 重新載入；主選單按鈕與寫死在程式裡的文字要完整重開遊戲；任務書要重進世界。
- **閃退且沒有崩潰紀錄**：先把 `mods/jecharacters-*.jar`（JEI 拼音搜尋）移走再試。
- **蜂籠上的蜂名不是中文**：放進背包幾秒會自動更正；你用命名牌取的名字永遠不會被改。
